# 📚 ExamPrep – Student Examination Platform

ExamPrep is a **mobile UI/UX design concept** created in Figma for students preparing for competitive and academic examinations.

The project focuses on creating a clean, simple, and user-friendly experience for students to access examinations, view their preparation progress, and review exam information before starting a test.

---

## 🎯 Project Overview

ExamPrep was created as a UI/UX practice project to explore mobile application interface design and Figma prototyping.

The project focuses on:

- Mobile UI design
- User flow
- Visual hierarchy
- Consistent spacing and typography
- Dashboard design
- Exam information presentation
- Basic wireframing and prototyping

The current design consists of three main screens representing a basic student journey from login to accessing an examination.

---

## 📱 Screens Designed

### 1. Login Screen

A simple login interface that provides students with an entry point into the application.

**Key elements:**
- Welcome message
- Email / phone input
- Password field
- Forgot password option
- Login button
- Sign-up option

### 2. Student Dashboard

A dashboard designed to provide students with an overview of their examination preparation.

**Key elements:**
- Personalized greeting
- Upcoming examination
- Exam information
- Subject-wise progress
- Recent results
- Bottom navigation

### 3. Exam Details

A dedicated screen that provides important information before starting an examination.

**Key elements:**
- Exam title
- Number of questions
- Exam duration
- Negative marking information
- Exam topics
- Instructions
- Start Exam button
